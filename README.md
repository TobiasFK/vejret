# Vejret

Personal home-screen weather app: Celsius first (°F alongside), saved places, current location, a 3-hour rain outlook, radar and a 14-day forecast.

Live at https://tobiasfk.github.io/vejret/

Data: Open-Meteo (forecast, place search), RainViewer and NEXRAD via Iowa Environmental Mesonet (radar), CARTO/OpenStreetMap (map), BigDataCloud (place name for current location). No API keys needed.
